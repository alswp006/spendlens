# SpendLens

## Platform
앱인토스 (Vite + React + TDS)

## One-liner
한국 직장인 10명 중 7명이 월말 '돈이 어디 갔지?'를 경험하는 가운데, 카드사 앱의 단순 내역 조회를 넘어 AI가 소비 패턴의 '낭비 구조'를 시각적으로 진단해주는 개인 재무 코치 앱

## Problem
국내 카드사/은행 앱은 거래 내역 나열에 그쳐 '왜 돈이 부족한지' 구조적 원인을 알 수 없음. 토스·뱅크샐러드는 연동은 되지만 실행 가능한 절약 액션을 제시하지 않아 '보고 끝나는' 앱으로 전락. 특히 2030 직장인은 구독 서비스 중복 지출, 배달비 과지출을 인지하지 못한 채 매월 반복함.

## Target Users
서울/수도권 25-38세 직장인, 월 소득 250-450만원, 지출 관리에 관심은 있으나 가계부 작성은 귀찮은 층

## Core Features
1. 카드사 SMS/이메일 파싱으로 자동 지출 분류 (연동 API 불필요, 개인정보 최소화)
2. AI 기반 '낭비 패턴 주간 리포트' - 구독 중복, 배달 과지출, 충동구매 시간대 분석
3. 동일 연령/소득대 익명 벤치마크 비교 ('또래보다 커피값 37% 더 씀')
4. 절약 가능 금액 자동 계산 및 '이번 달 목표 절약 챌린지' 설정
5. 월 1회 AI 재무 진단 PDF 리포트 생성 (공유 가능)

## Monetization
- Model: freemium subscription
- Estimated MRR: $1,200
- Reasoning: 무료: 기본 지출 분류 + 주간 요약. 유료(월 4,900원): 심층 패턴 분석, 벤치마크, PDF 리포트. 금융 리터러시 관심 높은 2030 직장인 타겟으로 전환율 3-5% 기대. 300명 유료 전환 시 약 $1,100-1,300 MRR. Mint의 보안 불신 문제를 'SMS 파싱만' 방식으로 회피해 신뢰도 차별화.
